# Semi-Supervised Learning Approach to Image Segmentation using Regularisation across Modalities

## Usage
1. Set hyperparameters as desired
2. Run Jupyter notebook and monitor the `<date> <time>.txt` log to see progress during training.
3. After running, copy .pkl files from different training runs unto `analyse-pkl` directory and run the analysis cell near the bottom of the notebook to plot important training data.
  > note that this is currently configured to analyse performance benefit between two models
